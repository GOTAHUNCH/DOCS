# Roadmap

Status vocabulary used throughout: **Live** (shipped and in use), **In development** (being built now), **Planned** (committed, not started), **Retired** (shipped in the prototype, replaced).

## Phase 1: Foundation (2025 - Q3 2026)

**Status: Complete**

The prototype proved the swipe interface and invisible-wallet onboarding, and showed that running our own markets is the wrong place to spend effort.

| Milestone | Status |
|-----------|--------|
| Prototype live (v0.26) | Live, retired |
| Privy authentication and embedded wallets | Live |
| Polymarket market data sync | Live |
| House-run markets and $HUNCH test token on Base Sepolia | Retired |
| ZeroDev smart accounts and session keys | Retired — replaced by Polymarket Deposit Wallets and session keys |
| Decision: build on the Polymarket Builder Program | Complete |
